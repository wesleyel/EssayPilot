# EssayPilot（MCP）

EssayPilot 不调用模型：评分、润色、批注都由你完成，再通过 MCP 写回，用户在网页上实时看到。
接入：`claude mcp add --transport http essaypilot http://127.0.0.1:8790/mcp`（服务需以 `-mcp` 启动；地址以实际部署为准）。完整接口见仓库 `docs/api.md`。

## 先看用户在看什么

- 用户说「这篇」「这一句」时先调 `get_ui_context`：返回当前打开的作文 id 和选中的文字。
- `list_annotations(essay_id, author="user")` 是用户自己做的标记：`question` 是疑问，要用 `reply` 回答；`issue` 是他觉得有问题的地方，可回复或加 `correction`。不要删除用户的标记。

## 评分

1. `get_rubric(essay_id=…)` 读细则（每次都读，不凭记忆），`get_essay(id)` 读题目与正文。
2. `submit_evaluation`：四个维度 content / language / structure / convention 各自不超过满分，之和等于 score；`corrections[].quote` 逐字摘自正文、kind 取细则里列出的纠错类别。纠错会成为可一键采纳的边注。
3. 需要补充的亮点、问题用 `annotate`。也可以直接用 MCP prompt `grade_essay` / `polish_essay` / `review_my_marks`。

## 标注要点

- `quote` 逐字摘自当前正文，短而唯一；重复出现用 `occurrence`（从 1 起）。返回结果里带 `error` 的条目是没找到原文，改 quote 后重试。
- kind：`highlight` 重点 / `good` 亮点 / `issue` 问题 / `question` 疑问 / `correction` 纠错（必须带 `suggestion`）。note 写具体问题，不写空话。
- 重点（highlight）只画能在别的作文里复用的句子：开头句、结尾句、承接与过渡词句（如 To begin with、As for…）、万能句型；不画只属于这篇内容的细节句，不确定能否复用就不画。label 写使用场景（2–6 字，如“开头表明来意”“引出第一点”“转另一个话题”“请求帮忙”“结尾祝愿”），note 留空，不解释字面意思。
- 其他边注（亮点、问题、疑问、纠错）只写一句，点明作用或错在哪，不复述原文。

## 题目与标签

- `subject`：`english`（`part-a` 小作文 10 分、`part-b` 大作文 20 分）| `politics`（`mayuan` `maozhongte` `shigang` `defa` `dangdai`，各 10 分）；创建后科目不可改。
- 分类 `category`：`part-a`、`part-b` 必填，候选值见 `list_types`；政治留空。
### 主题标签 `tags`

1–10 个，每个不超过 20 字，服务端去空白去重；PATCH 会**整体替换**，不能清空。以下命名约定服务端不校验，打标签时必须遵守，并优先复用库里已有的标签（先 `list_essays` 看现有标签）：

- **英语**：反映写法走向与语料，3–6 个，按「技法 → 情感 → 走向 → 主题」排列。
  - 大作文技法：`反差对比` `同类比较`（饼图/柱状图各项排序） `趋势变化` `多项同增` `图文互证` `寓意隐喻` `正反两面` `原因分析` `让步反驳`
  - 大作文情感：`积极赞扬` `理性审慎` `褒贬对照` `温情关怀`；走向：`呼吁倡导` `条件展望`（Only when…） `前景展望` `哲理收尾`
  - 小作文：`约定时间地点` `主动帮忙` `分点建议` `中外对比` `文化介绍` `推荐地点`/`推荐作品`/`推荐资料` `礼仪提醒` `活动介绍` `报名方式` `诚挚邀请` `承诺支持` `鼓励打气` `表达祝愿` `欢迎到访`
  - 末尾一个语料主题：如 `传统文化` `科技AI` `绿色出行` `文旅体验` `青年成长` `城市民生`
  - 例：`["反差对比","褒贬对照","让步反驳","哲理收尾","文旅体验"]`
  - 还没有正文时按题目要求预判写法，写完后再校正。
- **政治**：一律「板块-知识点」，板块取 `马哲` `政经` `毛概` `新思想` `史纲` `德法` `当代`；题目跨板块时可带其他板块的标签。例：`["马哲-矛盾","马哲-矛盾分析法","新思想-生态文明"]`、`["政经-资本有机构成","马哲-生产力"]`
- 不打来源或重复类标签：`2026真题` `第34题` `预测题` `Paul来信` `仿写练习` `电子邮件`，以及与题型重复的 `马原` `习思想`（这些信息放在标题里）。
